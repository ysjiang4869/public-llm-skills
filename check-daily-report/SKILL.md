# 日报填写检查

检查指定小组指定日期的腾讯文档日报填写情况，输出未填写成员名单。有任何内容均视为已填写。

## 参数

| 参数 | 说明 |
|---|---|
| `<DATE>` | 日期，格式 `M.DD`（如 `5.21`）；未指定则默认今天 |
| `--url` | 腾讯文档链接；未指定时回退环境变量 `DAILY_REPORT_URL` |
| `--group` | 小组名；未指定时回退环境变量 `REPORT_GROUP` |
| `--exclude` | 本次检查排除的成员，逗号分隔 |
| 环境变量 | `DAILY_REPORT_URL`（链接）、`REPORT_GROUP`（小组名） |

`url` 与 `group` 最终无值时脚本报错。

## 使用方式

用户说明要检查的日期（不说则默认今天），也可指定小组/链接/排除名单：
- "检查今天的日报 https://docs.qq.com/sheet/xxxx?tab=xxxx"
- "看看5.21谁没填日报"
- "查一下运营组的日报情况，张三和李四请假不用算"

## 执行步骤

```bash
python3 scripts/check_daily.py "<DATE>" [--group="<GROUP>"] [--url="<URL>"] [--exclude="<NAME1>,<NAME2>"]
```

对话中提到的链接/小组名/排除人员通过对应参数传入。脚本自动调用 mcporter（需已安装并配置 tencent-docs MCP 服务）获取数据并完成检查。

## 输出格式

```
5月21日 XX组 未填写日报（共 N 人）：
- 张三
- 李四
```

若全员已填写：

```
5月21日 XX组 未填写日报（共 0 人）：
全员已填写
```
